# Exemplos de Código em Aula

Repositório com exercícios e testes práticos desenvolvidos em aula utilizando estruturas condicionais, laços de repetição e `switch`.

## Estrutura dos Arquivos

### Linguagem C (`c/`)
- `calculo_media.c` — Lê duas notas, calcula a média e exibe aprovação/reprovação com operador ternário.
- `aprovado_reprovado_v1.c` — Verifica se o aluno foi aprovado, reprovado ou tirou nota máxima (`10`) usando `if`/`else` aninhado.
- `aprovado_reprovado_v2.c` — Segunda versão/cópia do exercício de verificação de aprovação e nota máxima (`10`).
- `contador_break.c` — Exemplo de laço `for` infinito controlado com condição de parada via `break`.
- `contador_loop_infinito.c` — Teste de contador com limite numérico muito alto em laço `for`.
- `calculadora_switch.c` — Leitura de dois números e operação com estrutura `switch` (caso de multiplicação implementado).

### C++ (`cpp/`)
- `leitura_idade.cpp` — Entrada e saída básica com `std::cin` e `std::cout`.
- `fatorial_fixo.cpp` — Cálculo do fatorial de `6` usando laço `for`.
- `fatorial_entrada.cpp` — Cálculo do fatorial de um número informado pelo usuário (`unsigned long long`).
- `tabuada_do_while.cpp` — Geração de tabuada de `1` a `10` utilizando `do...while`.
